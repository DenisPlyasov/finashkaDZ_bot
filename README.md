# FINdz

Telegram-проект для студентов Финансового университета: бот помогает смотреть расписание групп и преподавателей, хранить и отправлять домашние задания, а также присылает уведомления по расписанию и о новой почте. В репозитории также есть заготовка Telegram Mini App на React + Node.js.

## Что есть в проекте

### 1. Telegram-бот на Python

Основной вход: `main.py`.

Бот умеет:

- проверять подписку пользователя на обязательный Telegram-канал;
- показывать расписание группы;
- искать расписание преподавателя;
- сохранять избранные группы в `favorites.json`;
- отправлять уведомления по расписанию через `JobQueue`;
- показывать и добавлять домашние задания;
- подтверждать корпоративную почту `@edu.fa.ru` кодом из письма;
- проверять подключённые почтовые ящики по IMAP и присылать уведомления о новых письмах.

### 2. Telegram Mini App

Папка: `webapp/`.

Состоит из:

- `webapp/src` — фронтенд на React + Vite;
- `webapp/backend/server.js` — backend на Express + SQLite;
- `webapp/backend/fa_bridge.py` — Python-мост для поиска групп и преподавателей через `fa_api`.

На текущий момент mini app умеет:

- валидировать `initData` Telegram Mini App;
- проверять подписку на канал;
- искать группу или преподавателя;
- сохранять выбор пользователя в SQLite.

Полноценный вывод расписания в интерфейсе mini app пока не реализован: после выбора показывается только заглушка с названием выбранной группы или преподавателя.

## Зависимости

### Python-часть

В коде используются:

- `python-telegram-bot`
- `fa_api`
- `gspread`
- `oauth2client`

Также используются стандартные библиотеки Python: `sqlite3`, `imaplib`, `smtplib`, `json`, `logging`, `asyncio` и другие.

Отдельного `requirements.txt` в репозитории сейчас нет, поэтому зависимости нужно ставить вручную или собрать свой файл зависимостей.

### Webapp

Фронтенд:

- `react`
- `react-dom`
- `vite`

Бэкенд:

- `express`
- `better-sqlite3`
- `dotenv`
- `@tma.js/init-data-node`

## Обязательные локальные файлы

Для запуска Python-бота рядом с `main.py` должны быть созданы локальные файлы с секретами и параметрами:

- `token.txt` — токен Telegram-бота;
- `required_chanel_link.txt` — ссылка на обязательный канал;
- `required_chaned_id.txt` — `@username` или id канала для `get_chat_member`;
- `password_mail.txt` — пароль от почты `finashkadzbot@gmail.com`;
- `finashkadzbot-d8415e20cc18.json` — сервисный аккаунт Google для резервного копирования ДЗ в Google Sheets.

Файлы, которые создаются в процессе работы:

- `favorites.json` — избранные группы и настройки уведомлений;
- `mail_accounts.json` — подключённые почтовые аккаунты пользователей;
- `data/homework.db` — база домашних заданий и верифицированных email;
- `webapp/backend/miniapp.sqlite` — база mini app.

## Запуск Telegram-бота

### 1. Подготовьте окружение

Создайте и активируйте виртуальное окружение, затем установите зависимости:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install python-telegram-bot gspread oauth2client
```

Дополнительно должен быть установлен пакет `fa_api`, потому что он используется почти во всех сценариях расписания.

### 2. Подготовьте секреты

Создайте файлы:

- `token.txt`
- `required_chanel_link.txt`
- `required_chaned_id.txt`
- `password_mail.txt`
- `finashkadzbot-d8415e20cc18.json`

### 3. Запустите бота

```powershell
python main.py
```

Бот работает через polling.

## Запуск Mini App

### Frontend

```powershell
cd webapp
npm install
npm run dev
```

### Backend

Создайте файл `webapp/backend/.env`:

```env
BOT_TOKEN=your_bot_token
REQUIRED_CHANNEL=@your_channel
```

Установите зависимости и запустите backend:

```powershell
cd webapp\backend
npm install
node server.js
```

Backend по умолчанию слушает `http://localhost:8000`.

## Важные замечания

- `webapp/backend/server.js` сейчас жёстко ожидает Python-интерпретатор по пути `webapp/backend/.venv/bin/python`. Это Unix-путь. Для Windows его нужно адаптировать, иначе поиск групп и преподавателей из mini app не заработает.
- В репозитории нет единого файла зависимостей для Python.
- В коде есть файлы с историческими и резервными версиями, например `main-backup.py`.
- В `README` для `webapp` по умолчанию лежал шаблон Vite; он не описывал реальную архитектуру проекта.

## Основные сценарии бота

### Расписание

- поиск группы по названию;
- просмотр на сегодня, завтра, текущую и следующую неделю;
- просмотр расписания преподавателя;
- сохранение группы в избранное;
- уведомления по выбранным группам в заданное время.

### Домашние задания

- просмотр ДЗ по группе;
- добавление ДЗ после подтверждения корпоративной почты;
- хранение ДЗ в SQLite;
- резервное копирование в Google Sheets.

### Почта

- сохранение email и пароля приложения;
- IMAP-проверка входящих писем;
- Telegram-уведомление о новом письме.

## Текущее состояние

Проект уже содержит рабочую серверную логику Telegram-бота и базовую заготовку mini app. Самая функциональная часть сейчас — Python-бот. Mini app пока находится на стадии раннего прототипа: подписка и выбор пользователя уже реализованы, но экран с самим расписанием ещё не доведён до конца.
